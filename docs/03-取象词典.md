## 1. 为什么需要一本词典

如果每个穴位都靠美术手工搭景，361 个经穴不可能完成；如果用一个通用地形模板套所有穴位，取象比类就退化成贴图。

词典的作用是**把「命名」变成「可执行的场景语法」**：

```
穴名 ──拆字──▶ 象元 ──映射──▶ 原型 + 参数 ──实例化──▶ 场景
```

- **象元**：穴名中承载意象的最小单位，如「谷」「池」「门」。
- **原型**：一类地形/空间的语法模板，如 `valley`、`pool`、`pass`。
- **参数**：让同一原型在不同穴位长出不同形态的数值。
- **实例**：原型 + 参数 + 身体位置 + 时辰 + seed 的最终结果。

一本词典，三种人用：内容作者查字义，技术美术调参数，生成器读默认值。

### 2.8 修饰字（不单独成象）

有些字不生成地形，只修饰主象。它们同样要登记，但不进入原型映射。

| 类 | 字 | 作用 | 例 |
| --- | --- | --- | --- |
| 部位 | 手、足、臂、肩、肘、腕、口、头、面、项、背、腰、腹 | 限定位置与朝向 | 手三里、肩髃、口禾髎 |
| 序数/里程 | 二、三、五、大、小、少 | 限定次序、距离、体量 | 二间、三间、手五里、巨骨、少海 |
| 方位 | 上、下、内、外、前、后、中 | 限定层次与坡向 | 上廉、下廉、内关、外关 |
| 阴阳 | 阴、阳 | 限定光照、内外、寒暖 | 阴谷、阳溪 |
| 五音 | 宫、商、角、徵、羽 | 限定音色与五行气质 | 商阳、少商 |
| 动词 | 迎、扶、通、归、交、会、承、秉、率 | 限定气的动作与方向 | 迎香、扶突、通天、归来 |

**规则**：修饰字必须与至少一个象元共现；只有修饰字、没有象元的穴名，走「部位 + 默认原型」兜底，并在象卡中说明。

## 3. 命名构词法

穴名不是随机的，常见六种构词。生成器可以据此决定「谁是主象、谁是修饰」。

| 构词 | 例 | 主象 | 修饰 | 场景含义 |
| --- | --- | --- | --- | --- |
| 偏正（修饰+主象） | 合谷、曲池、温溜、悬钟 | 谷/池/溜/钟 | 合/曲/温/悬 | 地形 + 形态修饰 |
| 方位/阴阳 | 阴谷、阳溪、上廉、下廉、内关、外关 | 谷/溪/廉/关 | 阴/阳/上/下/内/外 | 光照、坡向、内外层次 |
| 数字/里程 | 二间、三间、手三里、手五里 | 间/里 | 二/三/五 | 间距、驿站、节奏 |
| 功能/祈愿 | 迎香、光明、归来、通天 | 香/明/来/天 | 迎/光/归/通 | 风、光、归处、高远 |
| 器物/身体 | 天鼎、巨骨、腕骨、肩髃 | 鼎/骨/髃 | 天/巨/腕/肩 | 形制、体量、位置 |
| 双主象并列 | 肘髎、口禾髎、颧髎 | 髎 | 肘/口禾/颧 | 骨缝 + 部位 |

**主从规则**：末字为主象的概率最高（谷、池、溪、门、海、泉、髎），首字多为修饰或部位限定。遇到「天鼎」这类双主象，取「鼎」为形、「天」为位。

## 4. 场景原型参数表

原型只定义「语法」，参数决定「这一处长什么样」。以下为初版默认值，实际以 `content/archetypes/*.json` 为准。

### 4.1 `valley` 谷

| 参数 | 范围 | 含义 |
| --- | --- | --- |
| `ridgeHeight` | 0–1 | 两侧山脊高度 |
| `ridgeDistance` | 0–1 | 两脊间距（越小越窄） |
| `convergence` | 0–1 | 谷口收束程度 |
| `mist` | 0–1 | 雾气密度 |
| `pool` | 0–1 | 谷底积水程度 |
| `wind` | 0–1 | 穿谷风强度 |

**合谷**：`ridgeHeight 0.7, ridgeDistance 0.45, convergence 0.9, mist 0.65, pool 0.5, wind 0.7`
**阴谷**：`ridgeHeight 0.9, ridgeDistance 0.3, convergence 0.7, mist 0.4, pool 0.8, wind 0.3`（更深、更冷、水更多）

## 5. 五输：经内的水形态

《灵枢·九针十二原》：

> 「所出为井，所溜为荥，所注为输，所行为经，所入为合。」

| 五输 | 水形态 | 位置 | 河道参数 | 粒子 |
| --- | --- | --- | --- | --- |
| 井 | 石隙初涌 | 指/趾端 | 最窄、最浅、下切 0.5mm | 向上冒，慢 |
| 荥 | 浅溪漫石 | 掌指/跖趾关节前 | 窄、浅、分叉 | 直行 + 抖动 |
| 输 | 溪流汇注 | 关节后 | 渐宽、有滩 | 汇流，略快 |
| 经 | 河渠正流 | 腕踝附近 | 宽、有岸、下切 2.5mm | 稳定快速 |
| 合 | 百川归海 | 肘膝附近 | 最宽、最深、下切 4mm | 回旋、下沉 |

这条表是**所有经脉共享的纵向节奏**。一条经从井到合，水面从「一线」走到「一潭」，用户的体感也从「紧」走到「松」。

## 7. 组合规则

生成器按以下顺序把「名」编译成「境」。

### R1 字解

先按古义拆字，不按现代汉语。

- 「合」= 合口、相合，不是「合并」。
- 「温」= 温暖/温水，不是姓氏。
- 「里」= 里程、居所，不是「里面」。

### R2 主从

末字为主象，首字为修饰；双主象时按「形 + 位」拆分。

```
合谷 → 主: 谷 (valley)   修: 合 (convergence)
曲池 → 主: 池 (pool)     修: 曲 (bend)
天鼎 → 形: 鼎 (vessel)   位: 天 (sky/high)
迎香 → 动: 迎 (wind)     物: 香 (flora)
```

### R3 围合增强

`合、曲、环、关、阙` → 提高 `convergence` / `narrowness` / 回声。

### R4 方向修饰

`阴/阳、上/下、内/外、前/后` → 改变光照方向、坡向、湿度、内外层次。

- 阳：光从上方/外侧来，色温偏暖，雾少。
- 阴：光弱，色温偏冷，湿度高，水色深。
- 上/下：决定山脊在画面的上方还是下方。

### R5 时间修饰

`温、热、清、凉、寒` → 水温、雾密度、色温、粒子速度。

### R6 五输定流

井/荥/输/经/合 决定河宽、下切、流速、粒子行为（见第 5 节）。

### R7 经脉定色

经脉五行 + 经水 → 主色、水质、植被、音高。

### R8 体位定势

手/足、伸/屈、骨/肉、内/外 → 决定山谷朝向、尺度、围合感。

- 手背：开阔、向阳、风大。
- 掌侧：隐蔽、湿润、光少。
- 关节：转折、收束、回声。
- 骨缝：狭窄、幽深、滴水。

### 编译示例：合谷

```json
{
  "name": "合谷",
  "tokens": ["合", "谷"],
  "parse": { "head": "谷", "modifier": "合" },
  "archetype": "valley",
  "params": {
    "ridgeHeight": 0.7,
    "ridgeDistance": 0.45,
    "convergence": 0.9,
    "mist": 0.65,
    "pool": 0.5,
    "wind": 0.7
  },
  "context": {
    "meridian": "LI",
    "element": "金",
    "river": "江水",
    "stage": null,
    "role": "原",
    "region": "hand.dorsal"
  },
  "modifiers": ["convergence+", "spring@bottom", "sunlit"]
}
```

生成结果：两脊夹谷、谷口收束、谷底有泉与浅潭、风穿谷、光从外侧来。

## 8. 同象异境

同一个字，必须因经、因位、因五行而变。否则「取象」就变成了「贴图」。

### 8.1 四个「谷」

| 穴 | 经 | 位 | 身份 | 关键差异 | 画面 |
| --- | --- | --- | --- | --- | --- |
| 合谷 | 手阳明（金/江水） | 手背，两掌骨间 | 原 | 开阔、向阳、风大、水浅 | 明亮的谷地，雾从谷口涌入 |
| 阴谷 | 足少阴（水/汝水） | 膝腘，筋间 | 合 | 深、冷、水多、光少 | 幽谷深潭，一线天光 |
| 然谷 | 足少阴（水/汝水） | 足内侧，舟骨下 | 荥 | 小、石多、泉从石出 | 石隙细泉，苔藓 |
| 阳谷 | 手太阳（火/淮水） | 腕背，尺骨茎突前 | 经 | 向阳、水浅急、暖 | 阳光斜切的浅谷 |

| 穴 | 经 | 位 | 身份 | 差异 |
| --- | --- | --- | --- | --- |
| 曲池 | 手阳明（金） | 肘横纹外端 | 合 | 大河弯折，深潭，静水，倒影 |

| 穴 | 经 | 位 | 差异 |

## 10. 审核清单

新增或修改一个象元/穴位时，逐条检查：

- [ ] 字义有据，注明出处；有争议时标注「一说」。
- [ ] 象元或修饰字在总表中登记，未登记的先补词典。
- [ ] 原型存在；参数在允许范围内。
- [ ] 与同字穴位相比，场景有可辨识的差异（同象异境）。
- [ ] 与经脉五行、经水、五输身份一致。
- [ ] 场景描述能对应回真实解剖位置（象不离体）。
- [ ] 文案区分「原文 / 今释 / 设计演绎」。
- [ ] 无疗效宣称、无伪科学话术。
- [ ] 色盲/低视力用户可辨识（不只靠颜色）。
- [ ] 截图并排检查：能否一眼认出是「谷 / 池 / 门 / 海」。

## 11. 如何扩展

### 加一个象元

1. 在 `content/archetypes/` 找到或新建原型。
2. 在本文第 2 节登记：字义、类、原型、例穴。
3. 给出 2–3 个参数预设（不同穴位）。
4. 至少做一张对比截图，验证「同象异境」。

### 加一个原型

1. 定义参数 schema 与默认值。
2. 在 `packages/scene-gen` 实现 `height()` / `biome()` / `ambient()`。
3. 在 `tools/preview` 里能单独调参。
4. 补黄金测试与视觉回归。

### 加一个穴位

1. 按 schema 写 JSON：锚点、五输、身份、象元、文本。
2. 跑 `content:validate` 与 `content:lint`。
3. 在预览页调 seed 与参数。
4. 医理/文献/文案三审。
5. 截图归档，加入「同象异境」对比集。
